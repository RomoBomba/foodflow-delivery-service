# foodflow-delivery-service
FoodFlow — сервис заказа еды с персональным подбором. Репозиторий с результатами лабораторных работ по предмету "Разработка решений на технологических платформах" ИТМО

Для разработчиков:
- нужен JDK 21 и запущенный Docker;
- скопировать .env.example в .env и задать локальный пароль;
- выполнить docker compose up -d postgres;
- в конфигурации запуска backend указать DB_PASSWORD с тем же значением;
- запустить BackendApplication;
- проверить /api/health.
